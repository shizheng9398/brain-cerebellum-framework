# brain-cerebellum-framework
Optimization of Action Operation for ai Robot
· 思维流 R：大脑按语义单元流式输出的序列，R = (r₁, r₂, …)，每个 rᵢ 是一个语义单元（如“定位物体”“确认抓取点”“伸手”）。
· 动作流 A：小脑按动作块执行的高频序列，A = (a₁, a₂, …)，每个 aⱼ 是一个短时动作块。
· 可执行阈值 τ：一个判定函数，输入是思维流的一个前缀，输出是“该前缀是否已满足某动作原语的触发条件”。τ(R[1:k], p) ∈ {0,1}，p 是动作原语。
· 必要条件 N：一个统计量，N(p, g) 表示动作前提 p 对目标 g 的必要性强度，用“p 不满足时 g 的成功率”与基线的差值量化。
